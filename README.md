# Synapse Horizon

A live 3D AI data-centre dashboard that tracks Claude and Codex agents and subagents, styled like a strategy game.

## Quick start

```sh
vp install
vp dev
```

`vp dev` serves the app on `http://127.0.0.1:5173`.
